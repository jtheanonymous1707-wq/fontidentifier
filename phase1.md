# Write me a full implementation plan with step by step guide for phase 1

Here's the full Phase 1 implementation guide. The current stack uses **Next.js 16** (Active LTS)  and **react-image-crop v11**.[^1][^2]

***

## Phase 1: Project Setup \& Repo Structure

### Step 1 — Create Your GitHub Repo

1. Go to [github.com](https://github.com) → **New repository**
2. Name it `font-identifier` → set to **Public** (for portfolio visibility) → click **Create repository**
3. Clone it locally:

```bash
git clone https://github.com/YOUR_USERNAME/font-identifier.git
cd font-identifier
```

4. Create the two root folders:

```bash
mkdir web model
```


***

### Step 2 — Scaffold the Next.js App

Inside the repo root, run:

```bash
cd web
npx create-next-app@latest . --typescript --tailwind --eslint --app --src-dir
```

When prompted:

- **Would you like to use Turbopack?** → Yes
- **Import alias?** → Keep default `@/*`

Your `/web` folder structure will look like:

```
web/
├── src/
│   └── app/
│       ├── layout.tsx
│       ├── page.tsx
│       └── api/             ← API routes go here
├── public/
├── next.config.ts
├── tailwind.config.ts
└── package.json
```


***

### Step 3 — Install All Dependencies

Still inside `/web`, install everything you'll need upfront:

```bash
npm install @supabase/supabase-js react-image-crop axios
npm install -D @types/node
```

| Package | Purpose |
| :-- | :-- |
| `@supabase/supabase-js` | Connect to Supabase DB and Storage |
| `react-image-crop` | Crop UI for text region selection |
| `axios` | HTTP calls to Hugging Face Space API |


***

### Step 4 — Create the Python Model Folder

Back in the repo root, scaffold the `/model` folder:

```bash
cd ../model
mkdir scripts
touch app.py requirements.txt Dockerfile .env
```

Your `/model` structure:

```
model/
├── scripts/
│   ├── generate_dataset.py   ← Phase 3
│   └── seed_fonts.py         ← Phase 2
├── app.py                    ← Phase 4 (FastAPI)
├── requirements.txt
├── Dockerfile
└── .env
```

Add initial dependencies to `requirements.txt`:

```
fastapi
uvicorn
pillow
torch
torchvision
timm
python-multipart
supabase
python-dotenv
```


***

### Step 5 — Set Up Supabase

1. Go to [supabase.com](https://supabase.com) → **New Project** → name it `font-identifier`
2. Choose the **free tier** → pick the closest region to you (**Singapore** recommended for KL)
3. Wait for provisioning (~2 min), then go to **Project Settings → API**
4. Copy these three values — you'll need them shortly:
    - `Project URL`
    - `anon public` key
    - `service_role` key (for the Python seeding script)

***

### Step 6 — Set Up Supabase Client in Next.js

Create `/web/src/lib/supabase.ts`:

```typescript
import { createClient } from '@supabase/supabase-js'

const supabaseUrl = process.env.NEXT_PUBLIC_SUPABASE_URL!
const supabaseAnonKey = process.env.NEXT_PUBLIC_SUPABASE_ANON_KEY!

export const supabase = createClient(supabaseUrl, supabaseAnonKey)
```


***

### Step 7 — Configure Environment Variables

Create `/web/.env.local`:

```env
NEXT_PUBLIC_SUPABASE_URL=https://your-project-id.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=your-anon-key-here
NEXT_PUBLIC_HF_API_URL=https://YOUR_HF_USERNAME-font-identifier.hf.space
```

Create `/model/.env`:

```env
SUPABASE_URL=https://your-project-id.supabase.co
SUPABASE_SERVICE_KEY=your-service-role-key-here
```

> ⚠️ Add both `.env.local` and `.env` to `.gitignore` immediately — never commit secrets.

Update `/web/.gitignore` (already auto-generated by Next.js) and add at the root level:

```bash
# root .gitignore
model/.env
web/.env.local
```


***

### Step 8 — Create Your Hugging Face Space

1. Go to [huggingface.co](https://huggingface.co) → **New Space**
2. Name it `font-identifier`
3. SDK: choose **Docker**
4. Visibility: **Public** (for portfolio)
5. Click **Create Space**
6. Go to **Settings → Variables and Secrets** → add:
    - `SUPABASE_URL` → your Supabase URL
    - `SUPABASE_SERVICE_KEY` → your service role key

You'll push actual code here in Phase 4 — for now just keep the Space created and the URL noted.

***

### Step 9 — Verify the Setup

Run the Next.js dev server to confirm everything is wired:

```bash
cd web
npm run dev
```

Visit `http://localhost:3000` — you should see the default Next.js 16 welcome page. If it loads, Phase 1 is complete.

***

### Step 10 — First Git Commit

```bash
cd ..  # back to repo root
git add .
git commit -m "Phase 1: project scaffold, Next.js setup, Supabase client, env config"
git push origin main
```


***

## Phase 1 Checklist

- [ ] GitHub repo created and cloned
- [ ] `/web` Next.js 16 app scaffolded with TypeScript + Tailwind
- [ ] All npm dependencies installed
- [ ] `/model` folder structure created with `requirements.txt`
- [ ] Supabase project created (Singapore region)
- [ ] Supabase client configured in `/web/src/lib/supabase.ts`
- [ ] `.env.local` and `/model/.env` created with all keys
- [ ] `.gitignore` updated — secrets never committed
- [ ] Hugging Face Space created (Docker SDK)
- [ ] Dev server runs at `localhost:3000`
- [ ] First commit pushed to GitHub

Once all boxes are checked, you're ready to move to **Phase 2: Font Database Setup**.
