# Font Identifier API

FastAPI service for identifying fonts from images using a deep learning model and Supabase pgvector.

## Deployment

This space runs a Docker container on port 7860.
The model is a scripted Thoroughly EfficientNet-B0.
Inference is performed on CPU.
